# InsightBoard AI

Build "InsightBoard", a React + TypeScript + Tailwind analytics dashboard.

KEY FEATURE: upload a CSV, auto-detect column types, and instantly generate KPI cards, line/bar/pie charts, and filters (date range, category, search) that update all charts together.

Also: sortable virtualized table for 10k+ rows, export filtered data to CSV, saved views.

SIGNATURE: "Ask your data" box that converts plain English ("sales by region last 3 months") into a chart using rule-based parsing.

Accessibility: keyboard navigation, aria labels, Lighthouse 90+.
